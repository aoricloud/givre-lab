# Étape V8 : la masse de chaque case et la page habillable (la fiche des valeurs)

Écrite **avant** les calculs, selon `AGENTS.md` règle 7 : pour chaque valeur ou chaque propriété attendue, un identifiant `V-V8-xx` (cité par le test), ce qu'elle dit, sa source ou son calcul indépendant, la tolérance (aucune : tout est exact) et le critère de réussite. Un script (`essai-v8-outils/verifier_ids.py`) lit les tests et cette fiche et vérifie que **chaque identifiant cité par un test existe ici, que chaque identifiant d'ici est cité par le test que la ligne « Test » nomme, et que ce test porte bien cet identifiant** (la relecture Opus de G3 avait trouvé quatre identifiants de test qui ne suivaient pas la fiche).

Les valeurs de ce document ne viennent pas d'un article (les masses de la neige ne sont pas publiées : l'article ne donne que des images et des réglages, voir G1 et G2) : **ce sont des définitions de l'export** (une unité, un ordre, une géométrie) et des égalités avec une autre lecture du même calcul. Les seules sources sont donc : **la doc de `src/vitrine.rs`** (« La masse de chaque case »), **la bibliothèque** (`Neige::valeurs_du_cristal`, étape G1 ; `rendu_hex`, G1 et V7) et **un calcul à la main** fait à part (Python, `essai-v8-outils/verifier_unite.py` : l'unité, la bascule du dégradé, l'ordre canonique). Aucune valeur n'est tirée du prototype pour devenir un test « juste ».

## Les critères (écrits avant les calculs)

1. **L'unité** : la masse exportée de la case `i` est `brut >> 21` (`brut` : le `.0` de `c`, un `Q31.32` ; 0 si la case n'est pas rattachée). Critère : le dégradé de `rendu_hex` pour `plein = 3 × 2^31` est **une fonction de la masse exportée** : `t = floor(min(masse, 3072) / 3)` ; les deux extrémités de l'intervalle de `brut` qu'une masse représente ont la même couleur.
2. **L'ordre** : celui de `Hexagone` (`r` croissant de `−R` à `R`, `q` croissant dans la rangée), écrit dans la doc par deux boucles et une formule fermée ; critère : les deux écritures (et `Hexagone::index`) donnent le même indice pour chaque case de six rayons.
3. **La géométrie et le pixel** : ceux de `rendu_hex` (`X = −(√3/2) r`, `Y = −(q + r/2)`, `√3` par `A/B`), recopiés dans la doc ; critère : un rastériseur écrit **d'après la doc seule** redonne `givre_nette_pixel` octet pour octet.
4. **L'instantané** : un tampon de l'état ; démarrer l'efface, préparer le refait, jouer ne le change pas, lire n'efface rien ; sans neige la préparation rend 0.
5. **La page** : ne plus figer ce que la page écrit, figer ce qu'elle promet : les identifiants, les phrases d'honnêteté, `lecture.js` pur, le canvas de la neige non pixélisé, les exportations, aucune ressource chargée du dehors, un poids borné ; critère : une page rhabillée à la façon du guide passe tout, chaque page fautive (une faute) échoue.
